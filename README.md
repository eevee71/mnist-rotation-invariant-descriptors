# Rotation-Invariant MNIST Classification Using Itô-Hermite Polynomials

This repository contains the code for our research on **Rotation-Invariant MNIST Classification Using Itô-Hermite Polynomials**. We use these polynomial functions to approximate images and extract rotation-invariant descriptors, evaluating the approach on the MNIST12K and MNIST-Rot datasets.

## Overview
Rather than relying on computationally heavy architectures, this project demonstrates that rotation-invariant digit classification can be achieved using a streamlined, mathematically grounded approach. 
We approximate images using polynomial functions to extract invariant features, which are then passed to lightweight learning models such as QDA and MLP. The method provides robust performance on rotated benchmarks while remaining highly efficient.

## Datasets
For our evaluation, we employ the MNIST-Rot and MNIST12K datasets, which comprise 62000 grayscale digit images. 
The MNIST12K subset was sampled directly from the original MNIST database, whereas MNIST-Rot was generated by applying random rotations from range $[-\pi, \pi]$ to the MNIST12K images. 
The data is partitioned into a 50000-sample test set and a 12000-sample training/validation split. We divide the train/val set into 10000 training images and 2000 validation images.  

**Setup Instructions:**
Download the necessary files from the [ICML 2007 Data repository](https://www.iro.umontreal.ca/~lisa/icml2007data/) and place them directly into the `data/` folder:
* `mnist.zip`
* `mnist_rotation_new.zip`

## Main Experiment: Rotation Invariance Evaluation (`experiments/run_seed_variance.py`)   
We assess our representation using three specific data combinations to thoroughly test rotation invariance:
1. **Unrotated Train + Rotated Test:** Models are trained on standard MNIST12K and tested against the pre-rotated MNIST-Rot dataset.
To ensure proper alignment between the unrotated grid and the pre-rotated dataset, the spatial dimensions of the MNIST-Rot test set are transposed.
2. **Fully Rotated:** All subsets (training, validation, and testing) are sourced from the MNIST-Rot dataset.
3. **Dynamic Test Rotation:** All subsets (training, validation, and testing) are sourced from the MNIST12K, but random rotations ($[-\pi, \pi]$) are dynamically applied to the test images.
Each setup is evaluated across 10 independent runs using different random seeds for the training and validation splits.

## Repository Structure

* **`main.py`**   
Executes the core benchmark (training on MNIST12k, testing on MNIST-Rot) and saves the resulting QDA and MLP confusion matrices as `.png` files to the `results/` directory.

* **`src/experiments/`**  ([src README](src/README.md))  
Contains experimental setups and scripts ([experiments README](src/experiments/README.md)).

* **`src/models/mlp.py`** ([src README](src/README.md))  
Contains the PyTorch implementation of the Invariant MLP classifier.

* **`data/`**  
Stores the downloaded dataset files and contains `dataloader.py`.

* **`results/`**  
Output directory for storing generated visualizations, including the confusion matrix `.png` files generated by `main.py`.
